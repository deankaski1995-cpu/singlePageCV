# singlePageCV
A single page CV with HTML
In this project i use an HTML with semantic and open graph meta tags for search engine and social media optimization. Also notable is the use of a favicon.  
To open the file locally clone the repository, navigate to the folder, and open index.html in any modern web browser (or use a tool like the VS Code Live Server extension).
